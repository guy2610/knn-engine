# Open Specification Questions

No baseline behavioral questions are currently unresolved.

New questions should be added here when they affect externally observable system behavior and cannot yet be resolved responsibly.

Implementation and architectural decisions belong in design work or ADRs rather than in this document.

## Deferred Questions

The following are intentionally not specification questions yet:

- exception versus result-based error handling
- class hierarchy
- templates versus runtime polymorphism
- thread-pool design
- networking protocol
- serialization implementation
- Boost.Asio
- OpenTelemetry
- pybind11
- ONNX Runtime versus LibTorch
- index data structures

Those should be decided only when the relevant implementation milestone requires them.
